### API Base URL

```

```

### মূল API Endpoints

```
🔐 Authentication
POST /auth/register    - নতুন ব্যবহারকারী নিবন্ধন
POST /auth/login       - ব্যবহারকারী লগইন
GET  /auth/me          - বর্তমান ব্যবহারকারীর তথ্য

👥 User Management
GET    /users          - সকল ব্যবহারকারী
GET    /users/:id      - নির্দিষ্ট ব্যবহারকারী
PUT    /users/:id      - ব্যবহারকারী আপডেট
DELETE /users/:id      - ব্যবহারকারী মুছে ফেলা

🍽️ Meal Management
POST /meals            - নতুন মিল এন্ট্রি
GET  /meals            - মিল তালিকা
PUT  /meals/:id        - মিল আপডেট
GET  /meals/summary    - মিল সামারি

💰 Financial Management
POST /expenses         - নতুন খরচ এন্ট্রি
GET  /expenses         - খরচ তালিকা
POST /bills/generate   - মাসিক বিল জেনারেট
GET  /bills            - বিল তালিকা

📊 Reports
GET /reports/dashboard - ড্যাশবোর্ড সামারি
GET /reports/monthly   - মাসিক রিপোর্ট
GET /reports/expenses  - খরচ বিশ্লেষণ
```
